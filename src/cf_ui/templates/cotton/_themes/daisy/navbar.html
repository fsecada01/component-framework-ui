{% comment %} Toggle `hidden` rather than adding `flex`: both are display utilities in the same layer, and Tailwind emits `hidden` last, so adding `flex` to an element that keeps `hidden` would never show it. Removing `hidden` leaves the div at its default display on mobile, and `lg:flex` (a media query, emitted after the base utilities) governs desktop either way. {% endcomment %}
